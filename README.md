# منصة نور التعليمية 🎓

منصة تعليمية كاملة: واجهة React + خادم Node.js/Express + قاعدة بيانات SQLite مدمجة (مش محتاجة أي تثبيت خارجي).

## المميزات

- **صفحة رئيسية** بتصميم متحرك غني + صفحة لكل كورس (تفاصيل + سعر + الدروس)
- **تسجيل ودخول الطلاب** بالإيميل وكلمة السر
- **الحساب الجديد بيكون غير مفعّل** لحد ما الأدمن يفعّله، ومش بيقدر يطلب كورس قبل التفعيل
- **دفع يدوي** (انستاباي أو محفظة إلكترونية) بدون بوابة دفع + زرار واتساب لفريق المبيعات
- **طلبات الاشتراك بتروح للأدمن كطلبات معلّقة**: قبول أو رفض، والقبول بيفتح الكورس للطالب فورًا، والطالب بيشوف حالة طلبه (قيد المراجعة / مقبول / مرفوض)
- **لوحة تحكم أدمن**: طلبات الاشتراك، تفعيل/إيقاف الطلاب، فتح/قفل كورس لطالب معيّن، رفع وإدارة الفيديوهات، إعدادات الدفع
- **الفيديوهات بتتخزن على الموقع نفسه** وبتتشغل ببث آمن (Range streaming) للطالب المشترك بس، مع تعطيل زر التحميل وقائمة كليك يمين
- **عربي + إنجليزي** بضغطة زرار، و**وضع ليلي**، ومتجاوبة مع الموبايل
- **أمان**: تشفير كلمات السر (bcrypt)، جلسات JWT في كوكيز httpOnly، حماية CSRF، تحديد معدل الطلبات (rate limiting)، Helmet headers، تحقق من المدخلات (zod)

## التشغيل (محليًا)

محتاج Node.js نسخة 18 أو أحدث.

```bash
# 1) الخادم
cd server
npm install
cp .env.example .env        # عدّل JWT_SECRET وبيانات الأدمن لو حابب
npm run seed                # ينشئ قاعدة البيانات + الأدمن + 4 كورسات تجريبية
npm start                   # يشتغل على http://localhost:4000
```

```bash
# 2) الواجهة — جاهزة ومبنية مسبقًا في client/dist
# لو حابب تعدّل التصميم وتعيد البناء:
cd client
npm install
npm run build
```

الخادم بيقدّم الموقع كاملًا من `http://localhost:4000` (الواجهة + الـ API من نفس السيرفر).

> للتطوير: `npm run dev` جوّه `client` بيشغّل Vite على 5173 مع proxy للـ API.

## بيانات الدخول الافتراضية

| الدور | الإيميل | كلمة السر |
|---|---|---|
| أدمن | admin@noor.com | Admin1234 |

غيّرها من `.env` قبل `npm run seed` (أو عدّل الأدمن من قاعدة البيانات). أرقام الدفع (انستاباي/المحفظة) ورقم الواتساب بتتعدّل من لوحة الأدمن → إعدادات الدفع.

## رحلة الطالب

1. يسجّل حساب جديد → 2. الأدمن يفعّل الحساب → 3. يختار كورس ويحوّل المبلغ → 4. يبعت إثبات التحويل واتساب ويأكد الطلب → 5. الأدمن يقبل الطلب → 6. الكورس والفيديوهات بتظهر له.

## اختبارات اتعملت قبل التسليم

- تسجيل → الحساب غير مفعّل → طلب كورس مرفوض برسالة واضحة ✅
- تفعيل الأدمن للحساب → الطلب بيتسجّل كمعلّق ✅
- قبول الأدمن → الكورس بيتفتح للطالب / الرفض بيظهر للطالب كمرفوض ✅
- رفع فيديو MP4 من لوحة الأدمن ✅
- تشغيل الفيديو: المشترك 200، الزائر 401، بث جزئي Range 206 ✅
- كل الصفحات اتفتحت واتصوّرت على ديسكتوب وموبايل بالعربي ✅

## حدود معروفة

- منع تحميل الفيديو بيخلّي الحفظ صعب (مش مستحيل): أي فيديو بيظهر على الشاشة ممكن يتسجّل ببرنامج تسجيل شاشة. ده طبيعة الويب عمومًا.
- قاعدة البيانات SQLite مناسبة للبداية؛ لو المنصة كبرت جدًا ممكن ننقلها PostgreSQL.
- مفيش بوابة دفع آلية — الدفع يدوي بالتصميم المطلوب.
